# AGENTS.md

Guidance for AI coding agents working in this repository.

## Pull Requests

Every PR description must include before & after screenshots of each affected page or component, in a table:

```markdown
| Before | After |
| --- | --- |
| ![before](BEFORE_IMAGE_URL) | ![after](AFTER_IMAGE_URL) |
```

- Take "before" screenshots from `master` and "after" screenshots from the PR branch, using the same viewport and scroll position.
- Add one row per changed page or state (e.g. desktop & mobile).
- If a change has no visual impact, write "No visual changes" instead of the table.
